# BookHaven — Exigences utilisateur et tests de non-régression

**Règle (utilisateur, 2026-10-04) :** toute demande spécifique sur une fonctionnalité
reçoit un **test de non-régression automatisé**, et l'ensemble est rejoué avant
**chaque** livraison.

- **Ajouter une exigence** : une ligne `| Rxx | … |` ci-dessous et au moins un test
  qui l'affirme (nom de test préfixé `test_Rxx_` de préférence). Si le comportement
  ne peut être vérifié que sur un appareil réel, écrire `MANUEL : <raison>`.
- **Gate avant livraison** : `python scripts/run_regression.py` (pytest serveur +
  navigateur desktop/mobile + bout en bout, puis tests JVM Android). Tout doit être
  vert ; voir `CLAUDE.md`.
- **Intégrité du registre** : `tests/test_user_requirements_registry.py` échoue si
  une ligne n'a ni test existant ni mention MANUEL, ou si un test cité a disparu.
- Les tests navigateur n'utilisent que des livres simulés (routes Playwright) ou
  une base temporaire : ils n'écrivent jamais dans la bibliothèque réelle.

Légende plateforme : **S** serveur/API, **W** lecteur/interface web, **A** app Android.
